Unsigned builds — check before opening

Download SHA256SUMS and verify your installer. Only bypass a warning for a build you trust. These builds have no verified publisher signature; macOS builds are ad-hoc signed and unnotarized. Organization policy may prevent opening them.

  • Windows: SmartScreen may show “Windows protected your PC”. For a trusted build, choose More info → Run anyway, if available.
  • macOS: drag the app from the DMG to Applications and try opening it once. If blocked, go to System Settings → Privacy & Security → Open Anyway, then confirm Open.
  • Linux: make the AppImage executable. Without FUSE, use --appimage-extract and run squashfs-root/AppRun. The .deb needs compatible WebKitGTK libraries.

Your data stays with you.

Your recordings and analysis stay on your computer. Cached maps work offline, and the optional update check reads the latest version from the project website. While the startup update check is on, the startup map index request carries a first-start flag for each new UTC day, ISO week or month. The app remembers those periods locally and sends no installation ID or additional data with the flag. The install count uses only daily totals. Turning off the startup update check disables the flag. The app keeps a small local log without paths or personal data, which you can choose to attach to a GitHub issue.

This website has no analytics, cookies or external fonts. Your day/night choice stays in this browser. Downloads and issue reports open GitHub.

Datenschutz

Aufzeichnungen und Auswertungen bleiben auf deinem Rechner. Zwischengespeicherte Karten funktionieren offline. Die optionale Updateprüfung liest die neueste Version von der Projektwebsite. Wenn die Updateprüfung beim Start aktiviert ist, kennzeichnet die Kartenindex-Anfrage beim ersten App-Start eines neuen UTC-Tages, einer neuen ISO-Kalenderwoche oder eines neuen UTC-Monats den jeweiligen Zeitraum. Die App merkt sich die Zeiträume lokal und sendet mit der Kennzeichnung weder eine Installationskennung noch zusätzliche Daten. Für die Installationszählung werden nur Tagessummen verwendet. Wenn du die Updateprüfung beim Start deaktivierst, entfällt die Kennzeichnung. Die App führt ein kleines lokales Protokoll ohne Pfade oder personenbezogene Daten, das du bei Bedarf an ein GitHub-Issue anhängen kannst.
