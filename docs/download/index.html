Unsigned desktop alpha — check before opening

Download SHA256SUMS and verify your installer. Only bypass a warning for a build you trust. These alpha builds have no verified publisher signature; macOS builds are ad-hoc signed and unnotarized. Organization policy may prevent opening them.

  • Windows: SmartScreen may show “Windows protected your PC”. For a trusted build, choose More info → Run anyway, if available.
  • macOS: drag the app from the DMG to Applications and try opening it once. If blocked, go to System Settings → Privacy & Security → Open Anyway, then confirm Open.
  • Linux: make the AppImage executable. Without FUSE, use --appimage-extract and run squashfs-root/AppRun. The .deb needs compatible WebKitGTK libraries.

Your data stays with you.

Everything runs locally. No account, no uploads, no analytics, no automatic updates. Only maps come from the internet; cached maps also work offline. The app keeps a small local log without paths or personal data; nothing leaves your computer unless you attach the file to a GitHub issue.

This website has no analytics, cookies or external fonts. Your day/night choice stays in this browser. Downloads and issue reports open GitHub.
